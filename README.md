# 🚀 Personal Portfolio Website

A clean, responsive personal portfolio website built with HTML, CSS, and Bootstrap to showcase my projects, technical skills, experience, and contact details.

---

## ✨ Features

- **Fully Responsive:** Adapts seamlessly across mobile, tablet, and desktop screens using Bootstrap 5's grid system.
- **Project Showcase:** Highlights personal projects with descriptions, technology tags, live demo links, and GitHub repositories.
- **Skills Overview:** Organized breakdown of core programming languages, web development frameworks, and AI tools.
- **Smooth Navigation:** Includes smooth scrolling and an accessible navigation bar.
- **Contact Section:** Direct links to social profiles, email, and location.

---

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3, Bootstrap 5
- **Icons & Fonts:** Bootstrap Icons / FontAwesome, Google Fonts

---

## ⚡ Quick Start

No complex build steps or dependencies required. You can view it directly in any modern browser.
